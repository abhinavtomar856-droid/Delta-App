# Delta App

A simple User Management Web Application built using Node.js, Express.js, EJS, and MySQL.

##  Features

- Add new users
- View all users
- Edit user information
- Delete users using email and password
- Perform CRUD operations
- MySQL database integration
- EJS templates for dynamic pages
- Express.js routing

##  Technologies Used

- Node.js
- Express.js
- EJS
- MySQL
- MySQL2
- Method-Override
- Faker.js
